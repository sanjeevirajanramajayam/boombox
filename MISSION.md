# Mission: HTTP Caching & Proxy Architecture

## Why
Master HTTP caching mechanics, proxy server design, and cache invalidation strategies to build resilient, high-throughput backend services and pass backend engineering system design challenges.

## Success looks like
- Accurately explain and use RFC 9111 HTTP caching directives (`Cache-Control`, `ETag`, `If-None-Match`, `Age`, `Vary`).
- Build, configure, and debug forward and reverse caching proxies in Node.js / systems code.
- Implement production cache eviction strategies (LRU, TTL expiration, active purge).

## Constraints
- ADHD mode: highly structured, visual, 5-10 minute interactive lessons.
- Practical code and browser-based exercises.

## Out of scope
- Distributed multi-region CDN edge network operations (for now).
