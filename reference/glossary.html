HTTP Caching Glossary

Quick reference guide for core caching concepts & terminology.

Core Concepts

Origin Server
The upstream authoritative server that creates and hosts the definitive resource representations.
Caching Proxy (Shared Cache)
An intermediary server positioned between client and origin that retains response copies to serve future identical requests.
Cache Hit
When an incoming request matches a valid cached representation, returned directly without querying origin (X-Cache: HIT).
Cache Miss
When no valid entry exists for the request key, forcing the proxy to forward the request to origin (X-Cache: MISS).
Cache Key
The unique identifier used to look up cached items, typically constructed from the HTTP method and request URI.
Freshness & TTL
The duration during which a cached response can be served without revalidating against the origin server.
