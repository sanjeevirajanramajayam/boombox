# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1  | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in Boombox (such as an HTTP request smuggling vector, hop-by-hop header leak, or secret exposure in cassettes), please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Send an advisory via [GitHub Security Advisories](https://github.com/sanjeevirajanramajayam/boombox/security/advisories/new) or contact **Sanjeevi Rajan Ramajayam** directly via GitHub profile.
3. Include a minimal reproducible test script, curl trace, or proof of concept.

We appreciate your effort in responsibly disclosing issues and will respond within 48 hours.
