# HTTP Caching & Proxy Architecture Resources

## Knowledge

- [RFC 9111: HTTP Caching (IETF Standard, June 2022)](https://www.rfc-editor.org/rfc/rfc9111.html)
  The definitive standard replacing RFC 7234. Use for: authoritative semantics on `Cache-Control`, `Age`, validation models (`ETag`), and proxy caching rules.
- [MDN Web Docs: HTTP Caching](https://developer.mozilla.org/en-US/docs/Web/HTTP/Caching)
  Practical, clear guide to caching architectures. Use for: client vs shared cache behavior, freshness calculation, and validator negotiation.
- [High Performance Browser Networking by Ilya Grigorik](https://hpbn.co/http-caching/)
  Deep architectural breakdown. Use for: latency implications, round-trip elimination, and real-world performance budgets.

## Wisdom (Communities)

- [r/backend](https://reddit.com/r/backend)
  Community of backend practitioners. Use for: real-world proxy performance discussion, caching edge cases.
- [roadmap.sh Backend Community](https://roadmap.sh/backend)
